# Risky Delivery — 위험한 택배 배달

Unity 6.3 LTS **6000.3.18f1** 기반의 3D 카트 배달 게임입니다.
도로, 창고, 카트와 택배는 기본 도형으로 생성합니다.

## 챕터

### 1. 연습 배송

장애물이 없는 도로에서 이동과 감속을 익힙니다.
민트색 목적지에서 정차하면 배송 성공입니다.
성공 화면에서 Enter 또는 다음 챕터 버튼으로 공사 구간에 진입합니다.

### 2. 공사 구간

바리케이드 3개를 **오른쪽 → 왼쪽 → 오른쪽**으로 피해 배달합니다.
민트색 바닥 표시가 통과 가능한 틈을 안내합니다.
숫자 2 또는 화면의 ROADWORKS 버튼으로 바로 시작할 수도 있습니다.

- 택배 내구도는 100%로 시작합니다.
- 바리케이드나 도로 경계벽에 빠르게 충돌하면 내구도가 줄어듭니다.
- 벽을 향한 충돌 속도로 피해를 계산합니다. 바닥 접촉과 가벼운 저속 충돌은 피해가 없습니다.
- Space를 누른 저속 운행 중 가볍게 닿는 것은 안전합니다. 달리다가 Space를 누르면 감속할 거리가 필요합니다.
- 벽에 계속 붙어 있는 것만으로 피해가 반복되지는 않습니다.
- 피해를 받으면 택배가 빨갛게 깜빡이고 내구도 바가 줄어듭니다.
- 내구도 0%면 실패하며, 망가진 택배로는 배달을 완료할 수 없습니다.
- 배달 성공 시 남은 내구도에 따라 1~3등급을 받습니다 (90% 이상: 3, 50% 이상: 2, 그 미만: 1).

현재 흔들림은 시각 효과입니다. 택배 낙하, 경사로와 미끄러운 노면은 아직 구현하지 않았습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| Space | 감속 / 누른 채 이동하면 저속 운행 |
| R | 현재 챕터 재시작, 내구도와 시간 초기화 |
| 1 / 2 | 연습 배송 / 공사 구간 선택 |
| Enter | 챕터 1 성공 후 챕터 2로 이동 |

## 바로 플레이하기 (현재 PC)

`Builds/Windows/RiskyDelivery.exe`를 더블클릭합니다.
게임 창을 클릭한 뒤 **2번 키**로 새 공사 챕터를 선택하세요.
실행 파일은 로컬에 있으며 Git에는 포함하지 않습니다.
다른 PC로 옮길 때는 exe만이 아니라 `Builds/Windows` 폴더 전체를 복사합니다.

## Unity에서 실행

1. Unity Hub에 로그인하고 라이선스를 활성화합니다.
2. Projects → Add → Add project from disk에서 프로젝트 폴더를 선택합니다.
3. Unity 6000.3.18f1로 엽니다.
4. `Assets/Scenes/Delivery.unity`를 열고 Play를 누릅니다.
5. Game 화면을 클릭한 뒤 조작합니다.

프로젝트 설정을 다시 준비하려면 메뉴 **Risky Delivery → Prepare Project**를 실행합니다.
Windows 실행 파일은 **Risky Delivery → Build Windows**로 만듭니다.

## 검증 (2026-09-13)

- 전체 C# 컴파일 및 Unity Windows Development 빌드 통과.
- 실제 Windows 플레이어에서 아래 자동 검사를 그래픽 없는 모드와 그래픽 모드 모두 통과.
- 챕터 1 이동, 목적지 정차 후 성공, 챕터 2 전환.
- 실제 바리케이드의 이동 차단과 저속 충돌 무피해.
- 고속 충돌 피해, 벽에 붙어 있을 때 중복 피해 방지.
- 반복 충돌 시 실패, 실패 후 목적지에 있어도 성공하지 않는지 확인.
- 재시작 시 내구도·시간·위치·속도 초기화 및 현재 챕터 유지.
- 챕터 2의 세 틈을 실제 물리 이동으로 통과해 내구도 100% 배송 완료.
- 존재하지 않는 챕터 3으로 진행하지 않는지 확인.

게임 UI의 이번 챕터 변경에 대한 최종 화면 검토는 미완료입니다.
캡처는 시작 로고까지만 확보했고, 이후 캡처 전 게임 창이 종료되었습니다.

자동 검사 명령:

```text
RiskyDelivery.exe -batchmode -nographics -risky-smoke-test -logFile smoke.log
```

성공하면 `RISKY_DELIVERY_SMOKE_OK`를 기록하고 종료합니다.
로컬 로그: `Logs/smoke.log`, `Logs/visual-test.log`, `Logs/build.log`.
`Tools/Check-Compile.ps1`은 설치된 Unity 참조 DLL로 C# 컴파일만 검사합니다.

## 개발 방식

기능별로 구현 → 검증 → 결과 안내 → 커밋·푸시를 진행합니다.
Library, Temp, Logs, Builds 등 생성 파일은 Git에 포함하지 않습니다.
