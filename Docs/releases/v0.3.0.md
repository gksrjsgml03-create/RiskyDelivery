# Risky Delivery 0.3.0

파란 작업복의 배달원이 상자를 들고 다섯 구간을 통과하는 Windows용 싱글 플레이 게임입니다.

**다운로드:** 아래 Assets의 `RiskyDelivery-0.3.0-Windows.zip`을 받으세요. 전체 압축을 풀고 `RiskyDelivery.exe`를 실행합니다. GitHub의 `Source code` 파일은 실행용 게임이 아닙니다.

- WASD / 방향키: 걷기
- Shift 누르기: 달리기, 떼면 걷기
- Space: 감속하며 조심히 걷기
- R: 재시작 / Esc: 일시정지 / M: 음소거
- 1~5: 챕터 선택. 마지막 5단계 성공 시 최종 결과를 표시합니다.

속도가 빠를수록 충돌 반동과 상자 손상이 커집니다. 비, 언덕, 야간 교차로에서 안전한 배송에 도전하세요.

Windows 64비트와 DirectX 11 그래픽 환경이 필요합니다. 게임 내 UI는 영어입니다. 압축 안의 README.txt에 한국어 안내가 있습니다. 이번 배포는 코드 서명이 없는 ZIP 배포이며 설치 프로그램과 자동 업데이트 기능은 포함하지 않습니다. 새 버전은 별도 폴더에 압축을 풀어 실행하면 기존 로컬 기록을 이어서 사용합니다.

게임 계정과 서버 연결은 필요하지 않습니다. 별 등급·시간·음소거 설정을 사용자 PC에 저장합니다. 문제 제보: https://github.com/gksrjsgml03-create/RiskyDelivery/issues
