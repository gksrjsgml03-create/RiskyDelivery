# Risky Delivery 0.3.0

파란 작업복의 배달원이 상자를 양손에 들고 이동하는 5개 챕터의 3인칭 싱글 플레이 게임입니다. 카메라는 도로 진행 방향 기준 캐릭터 뒤에서 따라오며, 캐릭터와 상자는 이동 방향으로 함께 회전합니다.

## 실행

ZIP을 폴더에 풀고 `RiskyDelivery.exe`를 실행하세요. 다른 PC로 옮길 때는 폴더 전체를 복사합니다. Windows 64비트용입니다.

시작 화면에서 Enter를 누르거나 챕터를 선택합니다. 배송 목적지인 민트색 구역 안에서 정차하면 성공합니다. 1~4번 챕터를 마친 뒤 Enter로 다음 배송을 시작할 수 있습니다.

## 조작

- WASD / 방향키: 이동
- 왼쪽 또는 오른쪽 Shift: 누르고 있는 동안 달리기. 키를 떼면 걷기로 돌아옵니다.
- Space: 감속. 누른 채 이동하면 상자를 안정적으로 들고 천천히 걷기
- R: 현재 배송 재시작
- Esc: 일시정지·재개, 결과 화면에서는 메뉴로 이동
- M: 효과음 켜기·끄기
- 1~5: 원하는 챕터 선택

## 다섯 번의 배송

1. TRAINING — 이동과 감속을 익히고 목적지에서 정차합니다.
2. ROADWORKS — 장애물을 오른쪽, 왼쪽, 오른쪽으로 피해 통과합니다.
3. RAIN RUN — 파란 물웅덩이에 들어가기 전에 감속합니다. 빗길에서는 제동 거리가 길어집니다.
4. HILL DELIVERY — Space를 누른 채 안정적으로 언덕을 넘습니다. 급한 방향 전환은 택배를 떨어뜨릴 수 있습니다.
5. NIGHT SHIFT — 흰 정지선 앞에서 기다렸다가 새 초록불에 건넙니다. 초록불은 6초이며, 노란불은 진입 금지 예고입니다.

택배 내구도 90% 이상으로 도착하면 별 3개, 50% 이상이면 2개, 그보다 낮으면 1개입니다. 내구도가 0이 되거나 언덕에서 택배가 떨어지면 다시 시도합니다.

벽이나 차량에 부딪히면 반대쪽으로 튕기며 잠깐 비틀거립니다. 빠르게 부딪힐수록 반동과 상자 피해가 커지므로 장애물 앞에서는 Shift를 떼고 Space로 감속하세요. 가벼운 충돌은 작은 반동만 발생합니다.

## 기록과 이어 하기

챕터별 최고 별 등급, 최단 시간, 음소거 설정이 자동 저장됩니다. 이어 하기는 아직 완료하지 않은 첫 챕터의 출발점에서 시작합니다. 연습·재시작은 기존 최고 기록을 유지합니다.

1~4단계 성공 후에는 Enter로 다음 단계에 진입합니다. 마지막 5단계를 클리어하면 최종 결과 화면이 열립니다. 이전 기록이 채워져 있어도 중간 단계에서 최종 결과로 넘어가지 않습니다. 게임 창은 자동으로 닫히지 않으며 결과 화면에서 메뉴로 돌아가 재도전할 수 있습니다. 모든 배송에서 별 3개를 받아 총 15개에 도전해 보세요.

저장 폴더: `%USERPROFILE%\AppData\LocalLow\RiskyDelivery\Risky Delivery`

게임 창을 벗어나면 배송이 일시정지됩니다. 돌아와서 Esc를 눌러 재개하세요. 게임 종료는 시작 화면 또는 일시정지 화면의 QUIT GAME 버튼을 이용합니다.
